Phoveus reads two clocks: the on-chain market and the underlying market.

Phoveus is a market-clock intelligence agent for tokenized stocks on BNB Chain. It compares on-chain token prices with underlying reference prices, tracks whether the underlying market is open or closed, detects divergence, and locks execution during reopening-risk states. Crypto prediction-market mechanics remain available as a demo layer, while the RWA intelligence engine is the core hackathon feature.

Binance Agent OS — Integration plan

The panel above uses live Binance public market data (no API key) and a 24h price-action heuristic to produce trading calls. You can optionally route analysis through a language model (e.g. Claude) via your own backend proxy — never put an Anthropic API key directly in this frontend file, because anyone who opens "View Source" can steal it. For real order execution the hand-off point is the Binance Agent OS MCP server: once the agent issues a high-confidence call, it can invoke the MCP place_order tool, which still requires your explicit approval before execution — the same "approve before it executes" pattern used by other Agent OS builders.

// agent-os.config.json — drop into Claude Code / Cursor / custom agent { "mcpServers": { "binance-agent-os": { "url": "https://agent.binance.com/mcp/agentic", "auth": "BINANCE_AGENT_OS_TOKEN", "scopes": ["market_data:read", "spot_trade:approve_each_order"] } } } // flow: Phoveus agent -> analyse live data -> issue call // -> if user approves in this UI -> call MCP place_order tool // -> every order still requires manual approval (revocable any time) // -> optional LLM reasoning must go through a backend proxy; NEVER put // a language-model API key directly in frontend / browser code // For multi-leg: agent can issue several sequential place_order calls // inside an isolated Agentic sub-account
