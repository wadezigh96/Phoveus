Binance Agent OS — Rencana integrasi

Panel di atas menggunakan data pasar publik Binance secara langsung (tanpa API key) dan meminta Claude untuk menghasilkan sebuah call trading. Untuk eksekusi order sungguhan, bagian ini menjadi titik sambung ke Binance Agent OS MCP server: begitu agent mengeluarkan call dengan keyakinan tinggi, agent bisa memanggil tool MCP place_order yang tetap meminta persetujuanmu sebelum tereksekusi — persis seperti alur "approve before it executes" yang dipakai builder lain di Agent OS.

// agent-os.config.json — dipasang di Claude Code / Cursor / agent kustom { "mcpServers": { "binance-agent-os": { "url": "https://agent.binance.com/mcp/agentic", "auth": "BINANCE_AGENT_OS_TOKEN", "scopes": ["market_data:read", "spot_trade:approve_each_order"] } } } // alur: Phoveus agent -> menganalisa data -> mengeluarkan call // -> jika user setuju di UI ini -> panggil tool MCP place_order // -> setiap order tetap butuh approval manual (revocable kapan saja) // Untuk multi-leg: agent bisa mengeluarkan beberapa place_order berurutan // di dalam Agentic sub-account yang terisolasi
