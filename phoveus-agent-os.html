Binance Agent OS — Integration plan

The panel above uses live Binance public market data (no API key) and a 24h price-action heuristic to produce trading calls. You can optionally route analysis through a language model (e.g. Claude) via your own backend proxy — never put an Anthropic API key directly in this frontend file, because anyone who opens "View Source" can steal it. For real order execution the hand-off point is the Binance Agent OS MCP server: once the agent issues a high-confidence call, it can invoke the MCP place_order tool, which still requires your explicit approval before execution — the same "approve before it executes" pattern used by other Agent OS builders.
