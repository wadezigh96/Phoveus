# Binance Query Token Info

Use official token information to resolve token names, symbols, and contract addresses before Phoveus performs any wallet or on-chain action.

## Rules
- Prefer verified official data.
- Never infer a contract address from a ticker alone.
- Preserve the chain ID with the address.
- Pass resolved asset identity to RWA Research and Risk Guard.

This skill is read-only and cannot authorize transactions.
